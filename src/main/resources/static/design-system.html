Design System

인스타 감성 GONG9RI 디자인 시스템

오프화이트 뉴트럴 베이스에 코럴 · 핑크 · 퍼플 · 오렌지 웜 그라디언트 포인트를 더한 색상 팔레트와 타이포그래피 · 버튼 · 카드 · 뱃지 · 폼 · 검색창 · 찜하기 버튼 컴포넌트를 한눈에 확인하는 쇼케이스 페이지입니다. 이후 페이지들은 이 토큰과 컴포넌트를 그대로 재사용합니다.

브랜드 마크

라쿤 얼굴 모양의 "9" 라인아트 아이콘. 헤더 등 밝은 배경엔 회색 버전을 사용합니다. 흰색 버전은 어두운 배경이 필요할 때를 위한 예비 자산입니다.

타이포그래피

헤딩 · 본문 모두 Pretendard로 통일 (예전엔 헤딩에 둥근 인상의 Poppins를 썼으나 제거)

H1 — 담백한 헤드라인 Aa

H2 — 섹션 타이틀 Aa 가나다

H3 — 카드 그룹 타이틀 Aa 가나다

H4 — 상품명급 타이틀 Aa 가나다

Body Large — 18px 본문 텍스트 예시입니다. Pretendard 가나다라마바사

Body Base — 16px 기본 본문 텍스트입니다. 공동구매로 더 저렴하게, 함께 사면 더 즐겁게.

Body Small / Muted — 14px 보조 텍스트, 캡션 등에 사용합니다.

Caption — 12px, 라벨/메타 정보용

버튼

Primary(웜 그라디언트) / Secondary(아웃라인) / Ghost / 크기 variant
