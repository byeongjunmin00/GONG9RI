Design System

담백하게 정돈한 GONG9RI 디자인 시스템

화이트 · 라이트 그레이 무채색 베이스에 다크 세이지 그린 브랜드 포인트를 더한 색상 팔레트와 타이포그래피 · 버튼 · 카드 · 뱃지 · 폼 · 검색창 · 찜하기 버튼 컴포넌트를 한눈에 확인하는 쇼케이스 페이지입니다. 이후 페이지들은 이 토큰과 컴포넌트를 그대로 재사용합니다.

타이포그래피

헤딩 · 본문 모두 Pretendard로 통일 (예전엔 헤딩에 둥근 인상의 Poppins를 썼으나 제거)

H1 — 담백한 헤드라인 Aa

H2 — 섹션 타이틀 Aa 가나다

H3 — 카드 그룹 타이틀 Aa 가나다

H4 — 상품명급 타이틀 Aa 가나다

Body Large — 18px 본문 텍스트 예시입니다. Pretendard 가나다라마바사

Body Base — 16px 기본 본문 텍스트입니다. 공동구매로 더 저렴하게, 함께 사면 더 즐겁게.

Body Small / Muted — 14px 보조 텍스트, 캡션 등에 사용합니다.

Caption — 12px, 라벨/메타 정보용

버튼

Primary(다크 세이지 그린) / Secondary(아웃라인) / Ghost / 크기 variant

검색 입력창 (인라인)

컴포넌트 예시입니다 — 백엔드 검색 API가 아직 없어 입력만 되는 순수 UI이며, 제출 핸들러나 필터링 로직은 연결돼 있지 않습니다. 실제 메인 페이지 반영은 후속 계획입니다.

검색 팝업 패널

이 페이지 상단 헤더 우측의 돋보기 버튼(#search-toggle-btn)을 눌러보세요 — 헤더 바로 아래 전체 폭으로 펼쳐지는 팝업 패널(.search-popup)이 열립니다. 다시 누르거나 패널의 닫기 버튼(✕)을 누르면 닫힙니다(js/search-popup.js, 열기/닫기 토글만). 패널 안에는 검색 입력창 하나만 있고, 제출·실제 검색 실행 기능은 없습니다 — "최근 검색어" 등 콘텐츠 섹션은 백엔드 검색 API가 없어 의도적으로 넣지 않았습니다.

찜하기 버튼

컴포넌트 예시입니다 — 위시리스트 백엔드 API가 아직 없어 클릭 핸들러·상태 저장·API 호출은 없습니다. 기본(찜 안 함)과 .is-active(찜함) 두 가지 시각 상태만 보여줍니다.
