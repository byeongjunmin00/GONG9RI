- 시도: 검색어 티커 클릭 핸들러를 `openPanel`(항상 열기만)에서 `togglePanel`(열려있으면 닫기)로
  교체 — 오버레이가 열린 상태에서 티커를 눌러도 반응 없던 죽은 영역 버그 수정. 버튼 텍스트가

  `button { user-select: none }`을 전역으로 추가(직전 `[hidden]` 안전장치 작업에서 얻은 "개별
  사후 수정 반복하지 말 것" 교훈을 그대로 적용).

  클릭/포커스로 열기, 바깥 클릭·Escape·닫기 버튼으로 닫기)에 회귀 없음을 확인.
