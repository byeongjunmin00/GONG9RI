  - **(수동/실측) bootRun 검증은 재실행하지 않음**: Generate 로그에 적힌 `bootRun` 무효 키/유효 키 반복 기동 결과(앱 정상 기동 → `/api/products` 200 → 색인 실패 ERROR 로그 → 이후에도 `/api/products` 200)는 evaluate-guide의 범위(`./gradlew test` 중심의 계산적 평가 + 코드/문서 대조의 추론적 평가)를 넘는 별도의 수동 재현 실험이라 이번 Evaluate에서 직접 재실행하지는 않았다. 대신 그 결과를 뒷받침하는 코드 메커니즘(`ApplicationRunner` 제거로 `SpringApplication.callRunners()` 경로 자체를 안 타게 됨, `@Async`+`ApplicationReadyEvent`로 이벤트 발행 스레드도 안 막힘, try-catch로 예외가 밖으로 안 나감)을 코드로 직접 확인했고 Spring Boot의 알려진 동작과 부합해, 보고된 실측 결과가 근거 있다고 판단한다. 다만 이 부분은 Generate의 1인칭 실측 보고에 의존하며 Evaluate가 독립적으로 재현한 것은 아니라는 점을 명시한다.
