# 카카오 로그아웃 후 재로그인 시 강제 재인증

대상: auth/social-login
담당: 전용운

## 배경 / 요구

우리 앱에서 로그아웃한 뒤 "카카오로 로그인"을 다시 눌러도, 카카오 자체 로그인 세션(기본 24시간,
"로그인 상태 유지" 선택 시 최대 1개월 — 카카오 공식 문의 답변 기준)이 살아있으면 카카오가 로그인
화면 없이 바로 인가 코드를 내려준다. 실제 프로덕션(`gong9ri-production.up.railway.app`)에서 직접
재현 확인함: 로그아웃 → "카카오로 로그인" 클릭 → 화면 전환 없이 바로 재로그인됨.

요구사항: 우리 앱에서 로그아웃했다면, 이후 "카카오로 로그인"을 누를 때는 카카오 자체 세션과
무관하게 **항상 재인증(카카오 로그인 화면)을 거치게 한다.**

카카오 공식 문서(Kakao Developers REST API)에 정확히 이 용도의 파라미터가 있음:
`prompt=login` — "기존 사용자 인증 여부와 상관없이 사용자에게 카카오계정 로그인 화면을 출력하여
다시 사용자 인증을 수행하고자 할 때 사용". 알려진 제한: 카카오톡 인앱 브라우저에서는 미지원.

## 설계

- `AuthController.kakaoLogin()`이 조립하는 카카오 인가 요청 URL에 `prompt=login` 파라미터를
  추가하는 방향으로 간다. 다른 인가 파라미터(`client_id`, `redirect_uri`, `response_type`,
  `state`)와 나란히 추가한다.
- role 파라미터 유무(일반 로그인 버튼 vs 회원가입 페이지의 역할별 버튼)와 무관하게 카카오
  로그인 진입점은 전부 이 엔드포인트를 통하므로, 별도 분기 없이 항상 적용한다.

## 태스크

- [ ] 관련 테스트(`KakaoLoginTest` 등)에 인가 URL이 `prompt=login`을 포함하는지 확인하는
      검증 추가/보완

## 평가(통과) 기준
- `kakaoLogin()`이 생성하는 리다이렉트 URL에 `prompt=login`이 포함되는 것을 테스트로 확인
- `./gradlew test` 전체 통과
- 가능하면 실제 카카오 계정 로그인 상태에서, 우리 앱 로그아웃 후 재로그인 시도 시 카카오
  로그인 화면이 다시 뜨는지 수동 확인(로컬에 카카오 앱 설정이 없으면 생략 가능 — 코드 레벨
  확인으로 대체)

## 리스크/전제
- 카카오톡 인앱 브라우저에서는 `prompt=login`이 지원되지 않을 수 있음(카카오 공식 문서에
  명시된 제한) — 이 경우 인앱 브라우저에서는 기존처럼 세션이 유지된 채 통과될 수 있으나,
  이번 스코프에서 별도 분기 처리는 하지 않는다(알려진 한계로 기록).
