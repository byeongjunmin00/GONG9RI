# 메인 페이지 오픈예정 상품 카드 전용 안내 문구 개선 (완료)

대상: product/open-soon-card-notice
담당: 민병준 / 전용운 / 코딩 에이전트

## 배경 / 요구
- 메인 페이지에서 `openAt`이 미래 시각인 "오픈예정" 상품 카드는 공구팀 생성이 오픈 전이라 아직 불가능함.
- 일반 공구팀 미존재 카드 뱃지(`🔥 첫 공구팀 신설...`) 대신 이모지 없이 차분한 은은한 서브 텍스트(`8월 25일 14:00 오픈 예정`)를 노출함.

## 평가(통과) 결과
- [x] 오픈예정 상품 카드 하단에 이모지 없이 차분한 `8월 25일 14:00 오픈 예정` 텍스트 라인이 표기됨.
- [x] 일반 공개된 상품 카드는 기존 진행바 또는 첫 팀 신설 뱃지가 영향 없이 그대로 노출됨.
- [x] `./gradlew test` 통과.
