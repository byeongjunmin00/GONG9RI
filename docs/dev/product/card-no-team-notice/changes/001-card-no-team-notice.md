# 공구팀 없는 상품 카드 안내 문구 개선 (사이트 톤앤무드 반영)

대상: product/card-no-team-notice
담당: 민병준 / 전용운 / 코딩 에이전트

## 배경 / 요구
- 메인 페이지 상품 카드에서 공구 팀이 있는 상품은 프로그레스 라벨(`N명 참여 중 · M명 달성 시 성사`), 트랙 바, 퍼센트 배지(`X% 달성`)가 표기되어 정보가 풍부함.
- 반면 공구 팀이 없는 상품 카드는 하단 영역에 아무것도 표시되지 않아 높이 불균형이 생기거나 밋밋한 현상이 발생함.
- 사용자 확정 피드백: 상품 카드 자체가 이미 하나의 클릭 가능한 CTA 영역이므로, 과도한 트랙/박스 대신 컴팩트 태그 뱃지 스타일(4안 방식)에 `🔥 첫 공구팀 신설하고 최저가 도전!` 문구를 적용함.

## 확정 설계 (시안 4안 스타일 + 웜톤 불꽃 태그)

### 확정 시안 (컴팩트 태그 뱃지형)
- **문구**: `🔥 첫 공구팀 신설하고 최저가 도전!`
- **구성**:
  - `card-body` 하단에 컴팩트한 태그 뱃지 형태로 삽입.
  - 배경: 은은한 웜톤 서브 표면 (`var(--color-surface-alt)`).
  - 텍스트: Pretendard 700 bold, `var(--color-pink)`.
  - 형태: `--radius-sm` (4px) 의 각진 샌드박스 뱃지.

## 평가(통과) 결과
- [x] 공구팀이 없는 상품 카드 하단에 `🔥 첫 공구팀 신설하고 최저가 도전!` 뱃지가 밋밋함 없이 깔끔하게 렌더링됨.
- [x] 공구팀이 있는 기존 카드의 프로그레스 바 렌더링 및 클릭/찜 기능에 영향을 주지 않음.
- [x] 카드 그리드의 전체적인 레이아웃 균형과 톤앤무드가 조화로움.
