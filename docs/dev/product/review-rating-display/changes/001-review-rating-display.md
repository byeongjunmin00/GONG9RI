# 메인 카드 및 상세 페이지 리뷰 별점 (5성 채운별/빈별) / 리뷰 수 표기 개선 (완료)

대상: product/review-rating-display
담당: 민병준 / 전용운 / 코딩 에이전트

## 배경 / 요구
- 메인 페이지 상품 카드 및 상품 상세 페이지에 5성 별점(채운 별 `★` / 빈 별 `☆`)과 리뷰 수를 시각적으로 노출하여 구매자의 상품 신뢰도를 대폭 향상시킴.
- 사용자 확정 선택: **메인 카드 Option B (상품명 하단 독립 별점 라인)** + **상세 페이지 Option 1 (상품 제목 직하단 서브 라인)**.

## 평가(통과) 결과
- [x] 메인 상품 카드 상품명 하단에 5성 별점과 리뷰 수가 깔끔하게 렌더링됨.
- [x] 상품 상세 페이지 제목 하단에 5성 별점 및 리뷰 수 링크가 노출되고 클릭 시 리뷰 탭으로 이동함.
- [x] 리뷰가 없는 상품의 경우 `☆☆☆☆☆ 0.0 (리뷰 0개)`로 조화롭게 렌더링됨.
- [x] `./gradlew test` 통과 및 Redis 캐시 역직렬화 호환성 유지.
