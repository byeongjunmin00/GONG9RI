# 인기검색어 티커 — 오버레이 토글 + 버튼 텍스트 선택 방지

대상: product/search-trends
담당: 민병준

## 배경 / 요구

`[hidden]` 전역 안전장치 배포 후 사용자가 비로그인 상태로 사이트를 점검하다 티커에서 두 가지를 리포트했다.

> "검색창 클릭하면 오버레이가 뜨긴 뜨는데 아무데나 클릭하면 닫혀야 하는데 이쪽 부분 누르면 내가 글씨 쓸 수 있을 때 깜빡깜빡거리는 거 있지 그거처럼 되고 안 닫혀"

> (더블클릭 스크린샷) "이렇게 그냥 더블클릭하면 이렇게 돼 안 사라져"

## 진단

### 1) "글씨 커서가 깜빡인다" — 캐럿이 아니었다

티커는 `<button>`이라 텍스트 캐럿이 생길 수 없다. 두 번째 스크린샷(더블클릭 시 글자가 파랗게 잡힌 상태)으로 실체가 확정됐다 — **텍스트 선택 하이라이트**였다. 더블클릭하면 버튼 안쪽 글자가 선택되고 그 상태가 그대로 남는다.

사용자가 함께 본 보라색 테두리는 `.header-search-trends-ticker:hover { border-color: var(--color-purple) }`, 즉 마우스를 올려둔 hover 상태다. 티커가 2.2초마다 페이드아웃/페이드인으로 순환하는 것(`.is-swapping`)도 "깜빡임"으로 인지됐을 수 있다.

### 2) "안 닫힌다" — 실제 버그

티커는 오버레이를 여는 트리거이면서 동시에 오버레이 *바깥*(`.site-header__search` = `wrapEl` 안쪽)에 있다.

```js
document.addEventListener('click', function (event) {
  if (!wrapEl.contains(event.target)) {   // 티커는 wrapEl 안 → 무시됨
    closePanel();
  }
});

tickerEl.addEventListener('click', openPanel);   // 항상 "열기"만
```

그래서 오버레이가 열린 상태에서 티커를 누르면 `openPanel()`이 한 번 더 불릴 뿐 화면상 아무 변화가 없다 — **죽은 영역**이 된다.

`[hidden]` 전역 규칙 도입/개별 규칙 제거와는 무관하며, 티커를 만든 시점(2026-08-19)부터 있던 동작이다.

## 설계

### 1) 티커를 토글로

여는 트리거를 다시 누르면 닫히는 게 자연스럽다.

```js
function togglePanel() {
  if (panelEl.hidden) { openPanel(); } else { closePanel(); }
}
tickerEl.addEventListener('click', togglePanel);
```

이벤트 충돌은 없다 — 티커의 리스너가 먼저 실행되고, 뒤이어 버블링으로 도달하는 document 리스너는 `wrapEl.contains(target)`이 참이라 아무것도 하지 않는다.

### 2) 버튼 텍스트 선택 방지는 처음부터 전역으로

티커 하나만 고치면 텍스트가 있는 다른 버튼(오버레이 "닫기", 카테고리 태그, 최근검색어 항목 등)에서 같은 일이 반복된다. 직전 `[hidden]` 안전장치에서 얻은 교훈(개별 사후 수정을 반복하지 말 것)을 그대로 적용해 `base.css`에 전역으로 뒀다.

```css
button {
  -webkit-user-select: none;
  user-select: none;
}
```

버튼은 읽으라고 있는 텍스트가 아니라 누르라고 있는 컨트롤이므로, 선택되는 것 자체가 오해를 부른다.

## 평가(통과) 기준

- 오버레이가 열린 상태에서 티커를 누르면 닫힌다.
- 티커를 더블클릭해도 글자가 선택되지 않는다.
- 검색창 클릭/포커스로 여는 기존 동작, 바깥 클릭·Escape·"닫기" 버튼으로 닫는 기존 동작에 회귀가 없다.

## 배운 것

사용자가 말한 증상("글씨 커서가 깜빡인다")을 그대로 원인으로 받아들였다면 입력 요소나 포커스 쪽을 뒤졌을 텐데, 티커가 `<button>`이라 캐럿이 생길 수 없다는 사실에서 출발해 다른 후보(텍스트 선택 / hover 테두리 / 페이드 순환)를 놓고 봤고, 사용자가 추가로 보낸 더블클릭 스크린샷으로 확정됐다. **증상 서술과 실제 원인은 다를 수 있으니, 서술을 그대로 원인으로 옮기지 말 것.**
