# 모바일 썸네일 sticky + 알림 패널 잘림 수정

대상: frontend/mobile-fixes
담당: 민병준

## 배경 — 사용자 리포트 2건

> "휴대폰에서는 상품 상세 페이지 가면 아까처럼 사진이랑 카카오톡 공유하기가 스크롤 내리면 같이 내려와. 모바일은 어쩔 수 없는 건가??"

> "모바일에서 알림벨 누르면 알림창 다 짤려"

## 변경

상세 근거는 `design.md` 참고. 요약하면,

1. **썸네일 sticky** — 1열로 쌓이는 모바일에선 고정할 이유가 없어 `position: static`으로 되돌림. "어쩔 수 없는 것"이 아니라 데스크톱용 설정이 모바일에 그대로 남아 있던 것.
2. **알림 패널** — 벨이 아니라 헤더를 기준으로 좌우를 벌려서 화면 안에 들어오게 함.

## 진단에서 정정한 것

처음엔 "알림 패널에 모바일 대응이 하나도 없다"고 판단했는데 **틀렸다.** `@media (max-width: 420px)` 규칙이 이미 있었다. 다만 그게 **효과가 없는 조건**이었다 — 390px 화면에서 `min(320px, 90vw)`는 320px을 그대로 고른다. 그리고 폭을 줄여도 해결되지 않았을 문제였다(원인이 기준점이었으므로).

## 검증

- CSS 중괄호 균형 267:267, 낡은 420px 규칙 잔여 0
- 로컬 실서버 서빙 확인
- **검증 방법 자체에서 한 번 헛짚었다** — 처음 curl 결과가 옛 CSS라 "수정이 안 먹었다"고 판단했으나, 실제로는 이 프로젝트가 정적 자산에 걸어둔 10분 캐시(`WebMvcConfig`) 때문이었다. 캐시 우회 요청으로 다시 확인하니 전부 반영돼 있었다.

> 실제 휴대폰에서의 육안 확인은 사용자 몫이다(이 작업 환경엔 브라우저가 없다).
