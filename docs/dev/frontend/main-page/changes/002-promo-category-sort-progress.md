# 메인 페이지 — 프로모션 바 + 카테고리/정렬 + 카드 진행바

대상: frontend/main-page
담당: 민병준

## 배경 / 요구

친구 목업 피드백을 계기로 메인 페이지에 배너·카테고리·정렬·참여 진행바를 추가(백엔드는 `docs/dev/product/list-enhancements/`). 진행 중 실사용 피드백을 반영해 여러 차례 다듬음:
- 처음엔 220px 큰 그라디언트 히어로였다가, 실제 이미지 없이는 미완성처럼 보인다는 지적으로 슬림 공지 바로 교체.
- 카테고리 바와 상품 그리드가 붙어 보인다는 지적으로 여백(`margin-bottom: 32px`) 추가.
- 데모 상품 이미지가 깨져 있던 걸 발견(존재하지 않는 pexels 사진 ID) — 실제 존재하는 URL로 교체.
- 카드 호버가 밋밋하다는 지적으로 상승 폭·확대·그림자를 강화.
- "자세히 보기"가 죽은 링크라는 지적으로, 배너 슬라이드마다 실제로 이동 가능한 링크(인기 상품 상세/카카오 가입/그리드 스크롤)를 갖게 재작업.
