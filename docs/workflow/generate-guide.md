# Generate 가이드 (generate-guide)

실행 흐름의 **Generate(생성) 단계**에서 이 문서를 참고한다.
목표: **승인된 계획(ongoing 문서)대로** 코드를 구현한다.

## 원칙

- **승인된 계획대로만** 구현한다. 계획에 없던 범위를 임의로 넓히지 않는다.
- 계획을 벗어나야 할 상황이 생기면, 생성을 멈추고 **Plan으로 돌아가 재승인**을 받는다.
- 승인 전에는 어떤 파일도 수정/생성하지 않는다 (휴먼 게이트).

## 지킬 규칙

- 코드 작성 규칙은 **`docs/code-convention.md`**를 따른다 (계층 분리·생성자 주입·검증 등).
- 관련 **정책(`docs/policy/`)**이 있으면 그 규칙을 코드에 반영한다.
- 대상 기능의 **`design.md`**와 어긋나지 않게 구현한다.

## 산출물

- 계획(ongoing 문서)의 태스크를 하나씩 구현한다.
- **재시도라면 먼저 `docs/logs/`의 이전 Attempt를 읽어** 같은 접근을 반복하지 않는다.
- 구현 후, **이번 시도의 내용·접근을 `docs/logs/`의 Attempt에 `시도`로 기록**한다 (무엇을·왜). 상세: `docs/logs-guide.md`.
- 구현이 끝나면 Evaluate 단계로 넘어간다 (`docs/workflow/evaluate-guide.md`).
