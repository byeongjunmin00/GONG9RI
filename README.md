## 이 프로젝트에서 신경 쓴 것

기능을 "돌아가게" 만드는 것과 **"틀렸을 때 알아채게"** 만드는 것은 다르다고 보고, 후자에 시간을 많이 썼다. 아래 세 가지가 그 결과다.

### 1. 통과하는 테스트가 아니라, 실패해야 할 때 실패하는 테스트

기능을 고칠 때마다 **고친 코드를 되돌려 테스트가 실제로 깨지는지** 확인했다(역검증). 이걸로 **아무것도 지키지 못하는 테스트**를 실제로 잡아냈다.

상담 채팅의 "남의 대화를 구독할 수 없다"는 보안 테스트가 통과하고 있었는데, **권한 검사를 통째로 지워도 그대로 통과**했다. 테스트가 메시지를 서비스 직접 호출로 보냈고 브로드캐스트는 WebSocket 컨트롤러에서만 일어나, 침입자에게 애초에 아무것도 가지 않았기 때문이다 — **막혀서 안 온 게 아니라 보내지 않은 것**이었다. 실제 WebSocket으로 보내도록 고친 뒤에야 "지우면 실패한다"가 성립했다.

### 2. 외부 의존성이 죽어도 서비스는 살아있게

Redis를 실제로 끄고 확인한 결과 **상품 목록·상세가 500**이었다. 캐시는 "없으면 느릴 뿐"이어야 하는 부가 장치인데 "없으면 죽는 필수 의존"이 되어 있었다.

`CacheErrorHandler`로 fail-open 전환 후 같은 조건에서 **200 + 정상 데이터**(DB에서 직접 조회). 이 프로젝트의 다른 Redis 사용처(rate limit, 인기 검색어)는 이미 fail-open이었고, 캐시만 예외였던 것을 원칙에 맞췄다.

> 이때 함정을 하나 밟았다. `CacheErrorHandler` **빈을 선언하는 것만으로는 적용되지 않는다** — 스프링은 `CachingConfigurer`를 구현한 설정 클래스의 것만 본다. 빈만 만들고 다시 재보니 여전히 500이라 알았다. **컴파일되고 빈도 만들어지지만 아무도 안 쓰는** 종류의 실수다.

### 3. 실시간 채널은 HTTP 인가를 타지 않는다

관리자 1:1 상담을 붙이며 발견한 것: **STOMP 구독은 `SecurityConfig`의 인가 규칙을 거치지 않는다.** 기존 WebSocket 채널은 공구팀 정원이라는 공개 정보를 브로드캐스트해서 인증이 없었는데, 그 구조를 그대로 쓰면 **아무나 남의 상담을 실시간으로 훔쳐볼 수 있다.**

세 지점에서 막았다.

| 지점 | 방법 |
|---|---|
| 연결 | 상담 전용 엔드포인트를 permitAll 목록에서 **일부러 제외** → 핸드셰이크부터 로그인 요구 |
| 구독 | 채널 인터셉터가 `SUBSCRIBE`를 가로채 방 당사자/관리자만 통과 |
| 발행 | `@MessageMapping`에서 같은 판정을 다시 — 구독만 막으면 **남의 방에 메시지를 밀어 넣을 수 있다** |

REST·구독·발행이 **모두 같은 메서드**를 호출한다. 경로마다 따로 검사하면 한쪽만 빠뜨린다.

## 핵심 도메인

**참여자가 늘수록 1인당 가격이 내려가는 계단식 할인**이 이 서비스의 본질이다. 그래서 "정원을 넘겨 참가되는 일"이 절대 없어야 한다.

동시 요청 하에서 정원 초과를 막기 위해 **조건부 UPDATE 한 문장**으로 처리하고(영향받은 row 수로 성공/실패 판정), 결제 확정에는 **비관적 락**을 건다. 락 없이 상태값만 확인하면 두 트랜잭션이 모두 "아직 미결제"를 읽어 중복 확정될 수 있다 — 이건 팀원의 코드 리뷰에서 지적받아 고친 부분이다.

| 사건 | 원인 | 대응 |
|---|---|---|
| 반복되는 프로덕션 OOM | **JVM이 컨테이너 CPU를 48개(호스트 물리 코어)로 오인식** — 스레드풀이 그만큼 부풀었다. `jstack` 덤프 + 바이트코드 디컴파일로 확정 | `-XX:ActiveProcessorCount` 고정, 브로커 스레드풀 명시 |

| 호스팅 이전 | 크레딧 소진 임박 | DB·이미지 무중단 이관 ([런북](docs/deploy-guide.md)) |

## 실행

**MySQL과 Redis가 모두 필요하다.** Redis 없이 띄우면 상품 목록·상세가 500이 난다.

```bash
docker compose up -d          # MySQL + Redis + 앱
# 또는 직접 설치한 MySQL·Redis에 붙여서
./gradlew bootRun
```

`SENDGRID_*` · `KAKAO_*` · `PORTONE_*` 같은 비밀값은 `.env`(gitignore 대상)로 분리한다. 없어도 앱은 정상 기동하며, 해당 기능(메일·카카오 로그인·결제)만 로컬에서 테스트할 수 없다.

```bash
./gradlew test                # 전체 테스트
```
